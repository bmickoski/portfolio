## Context

I built TeamPulse as a side project to get hands-on with the React/Next.js ecosystem. The goal was not just a tutorial app but something that covers real production concerns: auth, role-based access, real-time updates, and patterns like intercepting routes that you rarely see in beginner resources.

The app lets teams create organizations, invite members, and track projects (called pulses) with status changes, comments, and a live activity feed.

## Tech stack

Next.js 15 (App Router), React 19, TypeScript, Drizzle ORM on Neon (serverless Postgres), NextAuth v5, TanStack Query v5, Zustand, Tailwind CSS v4, shadcn/ui, Vitest.

## Decisions

### Modal pattern: intercepting routes vs. a plain dialog

The pulses list needed a detail view. Three options: navigate to a separate page, open a dialog over the list, or use Next.js intercepting routes.

### Role-based access: where to enforce

Owner/member roles needed to gate team management, org settings, and destructive actions. The question was where to enforce: middleware, server action, or UI.

The answer was all three, at different layers:

- **Middleware** redirects unauthenticated requests before they reach any route
- **Server actions** re-validate the session and role on every mutation
- **UI** hides controls that the current role cannot use

The UI gating is a convenience. The server action guard is the actual security layer. Middleware handles the unauthenticated case early.

## Implementation notes

- **Server Components + Suspense**: data fetching happens on the server per route segment, with Suspense boundaries for the dashboard stats and chart to stream independently
- **Server Actions with two-layer validation**: client validates with React Hook Form + Zod before submitting; server action re-validates the same schema and checks session
- **Optimistic UI**: TanStack Query cache invalidation after mutations; removed the optimistic update for edits after discovering the infinite query cache shape (`InfiniteData`) is not a flat array
- **Infinite scroll**: `useInfiniteQuery` with URL-based status filter via `nuqs`; `IntersectionObserver` on the last card to trigger the next page
- **Testing**: Vitest + React Testing Library; pure utility functions (like `relativeTime`) tested with `vi.useFakeTimers()` and `vi.setSystemTime()` for deterministic time assertions
